Data Protection

Privacy Policy

Last updated: October 30, 2026

1. Our Commitment to Zero Telemetry

The pencil2d-mcp project is committed to absolute user privacy. We do not collect, store, transmit, or monetize any telemetry, analytics, personal information, prompt text, animation artwork, or project data.

2. Local Processing & Transport Architecture

The Model Context Protocol server operates strictly as a local process on your host machine:

  • Standard I/O Transport (stdio): All JSON-RPC 2.0 communication occurs directly through inter-process pipes between your AI client (e.g. Claude Desktop, Antigravity, Cursor) and the local Python server. No network sockets are exposed.
  • Local File Operations: All animations, frame PNGs, audio clips, and .pclx files are written and read strictly within your local designated directories.
  • No Cloud Phoning Home: The server never connects to external servers, analytics dashboards, or third-party tracking services during execution.

3. Showcase Website Privacy

This showcase website is a purely static website hosted on Vercel:

  • No Cookies or User Profiling: We do not set tracking cookies, session cookies, or advertising identifiers.
  • No Third-Party Trackers: No Google Analytics, Facebook Pixels, or external ad scripts are embedded on this website.
  • Server Access Logs: Standard, transient HTTP access logs (such as IP addresses and browser user-agent headers) may be automatically processed by our hosting provider (Vercel) to deliver static assets and protect against DDoS attacks in accordance with Vercel's Privacy Policy.

4. Package Registry Disclosures

When you install pencil2d-mcp using pip install pencil2d-mcp, your request is served directly by the Python Package Index (PyPI). PyPI collects basic connection logs in accordance with the Python Software Foundation Privacy Policy.

5. Policy Updates and Contact

If this policy is revised, updates will be reflected on this page with a revised date. For questions regarding data protection, please contact chrizmonsaji@proton.me or open an issue on our GitHub repository: github.com/chriz-3656/pencil2d-mcp/issues.
